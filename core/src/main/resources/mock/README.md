# 목업 데이터 (1차 MVP 시연용)

- **요금**: 한국소비자원(2025-12) 조사 범위(kWh당 270~590원) 안에서 사업자별 회원가·로밍가·비회원가를 근사한 값이다. **실제 현재 요금이 아니다.** 2차에서 사업자 공지 요금표로 교체한다.
- **충전소**: 시연 경로(판교 → 서울역, 약 23km) 주변에 임의로 배치했다. `alongRouteKm`·`detourKm`은 이 경로 기준 근사값이다. 고장(양재 aT센터), 사용 중(서초), 커넥터 불일치(한남), 이벤트 대상(양재 채비)을 일부러 넣었다.
- **장거리 시연 경로**(`stations_seoul_busan.json`): 서울역 → 부산역(약 410km) 경부고속도로 휴게소 충전소 13곳. 위치·거리는 근사값이고 사업자는 시연용으로 임의 배정했다(실제 휴게소 운영 사업자와 다를 수 있다). 신탄진은 고장, 건천은 커넥터 불일치로 넣었다. 도감에는 넣지 않는다.
- **차종**: 배터리 용량·전비는 공개 제원 근사값, VIN 접두어는 차종 판별 흐름 시험용 예시값이다.
