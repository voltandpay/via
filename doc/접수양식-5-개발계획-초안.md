# 접수양식 5번 — 개발 계획 (초안)

> 양식에 옮겨 적을 초안. 팀명·앱 이름은 확정 후 바꾼다.

## 5-1. 개발 환경
- Android(Kotlin 2.2), minSdk 28 / targetSdk 34, Jetpack Compose
- Pleos Connect Emulator(Android 14 Automotive) + Virtual Console에서 실동작 검증 완료
- 구조: 계산 로직은 Android와 분리된 순수 Kotlin 모듈(단위 테스트 70개), SDK는 Repository 계층 뒤에 두어 실차·에뮬레이터·시연 모드를 바꿔 끼울 수 있게 함

## 5-2. Pleos Connect SDK 사용 계획

| SDK / API | 사용 기능 | 앱에서의 역할 |
|---|---|---|
| **Vehicle – EvBattery** | 배터리 잔량(SoC) 구독, 배터리 에너지, 전비, 충전 스위치 상태 | 도착 시 배터리 계산, 충전 시작·종료 자동 감지 |
| **Vehicle – Gear** | 기어 선택 구독 | 주행/정차 판별 → 주행 중에는 터치 없는 화면만 표시 |
| **Vehicle – Odometer** | 총 주행거리 | 트립 거리 → 효율 운전 포인트 검증 |
| **Vehicle – CarInfo** | VIN | 차종(배터리 용량·커넥터) 자동 판별 |
| **NaviHelper** | 경로 정보(`onRouteStarted`, `RouteStateInfo`), **경유지 추가(`addWaypoint`)** | 경로상 충전소를 경유지로 바로 추가 |
| **FusedLocation** | 현재 위치 | 충전 시작 위치로 충전소 매칭 → 스탬프·이벤트 검증 |
| **TextToSpeech** | 음성 안내 | 주행 중 추천·확인 질문·스탬프 알림 |
| **SpeechToText (On-device)** | 예/아니오 인식 | 주행 중 화면 터치 없이 경유지 추가 확인 |

차량 제어 권한(`CONTROL_*`)은 사용하지 않는다(읽기 전용).

## 5-3. 일정
| 기간 | 내용 |
|---|---|
| ~10/25 | SDK 동작 검증(스파이크 2회), 설계, 1차 MVP 구현 |
| ~11/14 | 시연 영상, 실기 시연 리허설, 문서 정리 |
| 11/24~12/2 (본선) | 공공 충전소 실시간 상태 API 연동(고장 제외), 충전 후 실제 절약액 정산, 비피크 충전 보상, 주간 리포트·차종별 리그 |
| 이후 | 충전사업자 요금표 연동, 카페이 결제 연동, 사업자 이벤트 등록 화면 |

## 5-4. 데이터
- 충전소·요금: 1차는 시연 경로 목업(소비자원 공개 범위 근사), 본선에서 한국환경공단 충전소 공공 API·사업자 공지 요금으로 교체
- 개인 데이터: 차량·위치 데이터는 기기 안에서만 쓰고 서버로 보내지 않는다(1차 MVP는 서버 없음)
