# 유사 사례 조사 — EV 충전 비용 최적화 × 운전 리워드 × 게이미피케이션

> 작성일: 2026-10-25 · 재조사: 2026-11-02 (2-5절 추가, 매트릭스 갱신)
> 대상 기획: **A+ (충전비 + 통행료 = 총 이동비용 최적화)** + 리워드·게이미피케이션 레이어
> 조사 범위: 국내 현대차그룹 생태계, 국내 충전 앱·에너지 제도, 해외 리워드·경로 서비스, 연구 문헌

---

## 1. 결론

**요소별 선례는 있지만, 다음 네 가지를 하나로 묶은 서비스는 찾지 못했다.**

1. 차량 센서로 검증한 **효율 운전(전비)** 데이터
2. 충전비 + 통행료를 합친 **총 이동비용 경로 최적화**
3. 충전 **수요 분산의 대가**를 재원으로 하는 리워드
4. **충전 대기 시간**에 펼쳐지는 게이미피케이션 (차량 안, Pleos 앱)

선례들은 오히려 우리 기획의 약점(보상 재원, 결제)에 대한 답을 준다.

> **2026-11-02 재조사:** 결론은 같지만, 개별 기능은 생각보다 많이 나와 있다. **Pleos Connect 기본 내비**가 배터리를 보고 충전소 경유 경로를 안내하고, **충전왕**은 내 카드 기준 최저가를, **지지직**은 미션·포인트를, **Chargeprice**는 내 요금제 기준 최저가 경로를 이미 한다(2-5절). "차 안에서 경로에 충전소를 넣는다"·"멤버십 기준 최저가"는 각각만으로는 차별점이 아니다. 차별점은 **내 멤버십 요금 + 차가 읽은 배터리 + 음성 무터치 + 차량 센서로 검증한 보상을 차 안에서 한 번에** 잇는 것이고, 기본 내비와는 역할을 나눈다(경로 = 기본 내비, 그 경로 위 가장 싼 충전소·보상 = VIA).

## 2. 사례별 정리

### 2-1. 현대차그룹 생태계

#### 현대차 블루링크 「안전운전습관」 서비스
- **하는 일**: 블루링크 가입자의 주행 정보(급가속·급감속·심야 운행 등)로 안전운전 점수 산정 → 현대해상 보험 할인
- **보상 조건**: 최근 90일간 1,000km 이상 주행 + 70점 이상 → 커넥티드카-UBI 특약. 커넥티드카 할인 특약과 합쳐 **총 12% 할인** 보도
- **연계 제도**: 서울시 에코마일리지(승용차) 연동, 녹색실천 운전마일리지(90일 500km 이상 주행 시 85점↑ 3천, 95점↑ 5천 마일리지, 2025년부터 지급)
- **우리 안과의 관계**: 운전 → 보상 구조가 같다. 그러나 **안전**에 보상하고, 현대차 자체 텔레매틱스라 가속도 데이터를 쓴다. **서드파티 Vehicle SDK에는 속도·가속도 API가 없다** (스파이크에서 확인).
- **시사점**: 경쟁하지 말고 축을 나눈다 — **블루링크 = 안전 → 보험료**, **우리 = 효율 → 충전비**. 필요하면 블루링크 점수·에코마일리지와의 연동을 제안.
- ⚠️ 출처 대부분이 2019~2022년. 현재 할인율·조건은 확인 필요.

#### 현대·기아·제네시스 카페이 (인카페이먼트)
- **하는 일**: 인포테인먼트 화면으로 실물 카드 없이 결제. 주유소·**전기차 충전소**·주차장 등 약 4,000개 가맹점 (2023년 보도). 현대백화점 주차 요금 자동 결제 알림, F&B 사전 주문
- **이름**: 현대 카페이 / 기아 페이 / 제네시스 카페이 (기능 동일)
- **우리 안과의 관계**: 차 안 결제 수단. 최적화·보상 기능은 없다.
- **시사점**: **결제는 직접 만들지 않고 카페이 연동을 전제로 한다.** 시연에서는 결제 확인 화면만 보여주면 되고, 그룹 내 시너지도 설명된다. (I안 "Car Wallet"의 약점이던 '결제망 모킹' 문제 해소)
- ⚠️ 가맹점 수·지원 차종은 2023년 기준.

#### Pleos Connect 앱 마켓 현황
- 2026-09-07 신규 7종 추가 → **총 18종** (국내). 이용 차종: 더 뉴 그랜저, 디 올 뉴 아반떼 등
- 신규 7종: 카카오내비, what3words, Make My Day(경로), 멜론, Radioline, RaiDIO Auto, Pickle — **모두 내비·음악**
- 나머지 11종 목록은 확인하지 못함
- 42dot 발표: 향후 **게임, 차량 관리, 라이프스타일**로 확대 예정. 현대·기아·제네시스 차량에 2026년부터 앱 마켓 점진적 기본 탑재
- **시사점**: EV 충전·금융·리워드 카테고리는 아직 비어 있는 것으로 보인다. 진입 시점이 좋다.

### 2-2. 국내 충전 앱·에너지 제도

#### 한전 플러스DR / 전기차 충전 국민DR
- **플러스DR (제주 시범, 2021~)**: 재생에너지 출력제한을 줄이기 위해 전력이 남는 시간대에 충전 유도. 한전 충전기 400여 기를 전력거래소 수요자원으로 등록. 낙찰 시 **충전소·시간대를 고객에게 안내 → 예약 충전 → 요금 할인**
- **역할 분담 (2023 MOU)**: 한전 = 정보 중개 / DR사업자 = 자원 등록·입찰 / 충전사업자 = 고객 안내·요금 할인. 한전 로밍 플랫폼 **ChargeLink**로 민간 충전사업자도 참여 가능하도록 중개 플랫폼 제공
- **국민DR (2023)**: 스마트충전(V1G) 기반 전기차 충전 국민DR 사업 업무협약
- **우리 안과의 관계**: **수요 분산의 대가로 할인**하는 구조 = 우리의 ⑤ 보상 재원 구조와 같다. 다만 소비자용 화면·경험이 약하다.
- **시사점**: **"우리 앱이 DR 제도의 소비자 접점이 된다"** 로 사업성을 설명할 수 있다. 아이디어가 아니라 이미 있는 제도 위에 선다.
- ⚠️ 2021~2023년 보도. 인센티브 단가·현재 운영 상태 미확인.

#### EV Infra (소프트베리)
- 전국 충전기 33만 대+ 실시간 위치·상태, 고장·후기 커뮤니티, 회원카드로 로밍 충전 간편결제, 제휴 카드 할인
- **사업자 간 요금 비교, 경로 기반 비용 최적화는 확인되지 않음**

#### 티맵 (EV 충전)
- 전국 5만 기+ 충전기를 카드 없이 이용, 차량 내 "탭탭차지" 인증, 통합 결제수단, 운전점수
- **충전소를 경로에 포함한 비용 최적화는 확인되지 않음**

#### 일렉베리
- 충전소 검색·결제·충전 배달, 가입 포인트 1,000원·월 최대 3만 원 적립 (앱스토어 홍보 문구)
- (2026-11-12 추가) 사용자 리뷰(2024-06)에 "가지고 있는 멤버쉽 카드를 등록하면 거기에 맞춰 최저 단가가 지도에 표시"된다는 내용이 있다 → 등록 카드 기준 단가 표시는 휴대폰 앱에 이미 있다. 접수양식 비교표에서 △로 반영

#### 기타
- 충전 할인은 주로 **신용카드**에서 나온다 (예: 전월 실적 구간별 충전 요금 할인·적립)
- **사업자별 비피크(심야) 충전 할인 정책은 공식 자료를 찾지 못함** — 블로그 수준 자료만 존재

### 2-3. 해외 사례

#### Mercedes me Eco Coach (독일)
- **하는 일**: 운전·충전 챌린지 → 포인트 → **Mercedes me Charge 충전 바우처**, CO₂ 상쇄 등으로 교환. 온라인 커뮤니티로 경쟁
- 2022년 사용자 5만 명 돌파 기념 할인 충전 바우처 프로모션 (2022-10-31까지)
- **우리 안과의 관계**: **리워드·게이미피케이션 레이어와 가장 비슷한 선례.** 다만 휴대폰 앱이고 차량 안 경험은 아니다.
- ⚠️ 2022년 이후 소식 없음. 현재 운영 여부 불명.

#### Optiwatt / ev.energy (미국)
- **하는 일**: 비피크 충전 시 **전력회사(utility)가 보상금 지급**. 앱은 프로그램 중개
  - Ava Community Energy × Optiwatt (캘리포니아, 2025-05): 첫해 최대 $100 (가입 $75 + 연 $25/대)
  - Black Hills × ev.energy: 충전의 80% 이상을 비피크로 하면 여름 월 $8, 그 외 월 $4 (연 최대 $120)
  - RG&E × ev.energy: 가입 $150 + 월 보상, PayPal·Venmo 지급
- **우리 안과의 관계**: **⑤ 보상 재원 구조와 같은 모델**이 실제 사업으로 돌아가고 있다.
- 차이: 집 충전 중심. 차 안 경험·경로 최적화는 없다.

#### A Better Route Planner (ABRP)
- 날씨·지형을 반영한 전비 예측, 경유지·충전 시간 반영 경로 계획
- **충전비·통행료 합산 비용 최적화는 확인되지 않음**

#### TollGuru
- 통행료·연료비를 포함한 경로 비용 API (개발자용, 미국 중심). 충전소 요금 필드도 있음
- 소비자 앱·차량 앱은 아님

#### Intellias (차량 게이미피케이션 플랫폼 사례)
- 프리미엄 EV 제조사용으로 차량 텔레메트리 → 에코 점수·챌린지·보상·공유 업적을 인포테인먼트에 통합한 사례 (업체 홍보 자료, 성과 미검증)

### 2-4. 연구 문헌 — 에코드라이빙 게이미피케이션

- **2022 문헌 리뷰**: 39편 분석, 34편이 주행 중 게이미피케이션 보조 시스템. 흔한 요소 = 에코 점수, 리더보드, 보상, 챌린지, 이모지 피드백
- **효과 근거는 약함**: 효과를 평가한 13편의 연구 질이 대체로 낮음
- **후속 파일럿 연구**: 리더보드 순위·점수에 효과가 있었으나 표본이 작음. 참가자들은 **리더보드 재설계**와 **내적·외적 보상의 균형**을 제안
- **2017 EV 프로토타입**: 제동 데이터 + 머신러닝으로 에너지 이득 예측, 인포테인먼트에서 게이미피케이션 피드백

**시사점**: 포인트·랭킹만으로는 효과가 약하다. **실제로 아낀 돈을 중심에 두고, 게임 요소는 보조**로 쓰는 설계가 맞다. → 기획서에 설계 근거로 인용 가능.

### 2-5. 2026-11-02 재조사에서 새로 확인한 것

#### Pleos Connect 기본 내비 (현대차그룹, 2026-04 공개)
- **하는 일**: 배터리 충전량·온도로 목적지까지 갈 수 있는지 판단하고, **최적 충전소를 경유하는 경로를 안내** (아시아경제 2026-04-30). 그랜저 부분변경부터 적용, 이후 현대·기아·제네시스로 확대. 경사·교통 정보로 주행가능거리 예측을 높일 계획
- **확인 안 된 것**: "최적"의 기준(요금인지 거리·충전 속도인지), 멤버십 요금, 절약액, 보상
- **우리 안과의 관계**: **가장 가까운 기능**. 차 안 + 배터리 기반 경유 충전소. 경쟁하지 말고 역할을 나눈다 — VIA가 고른 충전소를 NaviHelper로 기본 내비 경유지에 넣는다

#### 충전왕 (ENlighten, iOS 평점 4.5·179건)
- **하는 일**: 내 차 등록 → 배터리 잔량에 맞춘 예상 요금, 회원가·로밍가·급속·완속 한눈에, **충전 요금과 내 카드를 분석한 최저가 추천**, 단골 충전소 요금 변동 알림, 결제 카드 할인 정보, **가는길 충전소 찾기**(2022-11), 멤버십 카드 신청(2023-03)
- **없는 것**: 차량 데이터 연동(잔량은 사용자 입력), 도착 배터리 예측, 음성, 보상. iPhone 앱
- **우리 안과의 관계**: **"내 멤버십 기준 최저가"는 선례가 있다.** VIA는 같은 비교를 운전 중 무터치로, 차가 읽은 배터리와 경로 위에서 한다

#### 지지직 (Empact Labs, iOS 평점 4.5·97건)
- **하는 일**: 충전·절전(충전 중 속도를 줄인 만큼 보상)·퀴즈·제보 **미션 → 포인트 → 네이버페이 포인트**, 충전 리워드 선물상자, 경유지 충전소 길찾기(2026-03), 회원가 먼저 표시(2026-07), 지지직페이(한전 충전소), 테슬라 차량 연동(충전 히스토리, 자동화 베타)
- **없는 것**: 차량 센서로 검증한 주행·충전 보상(테슬라 외), 차 안 앱, 도착 배터리 예측
- **우리 안과의 관계**: **국내 충전 미션·리워드의 가장 가까운 선례.** 미션 검증은 앱 기록 기반이다 → VIA의 차량 검증이 차별점으로 남는다

#### 일렉베리 (갱신)
- 앱 설명에 **"국내 유일, 경로 기반 충전소 안내"** — 목적지 입력 시 우회거리·통행료·충전시간·요금 계산, 경로를 벗어나지 않는 충전소 안내
- 테슬라·현대·기아·제네시스 차량 연동(맞춤 충전·제어, 워치), 일렉베리 카드 결제 시 민간 3%·공공 1% 적립
- → 기존 매트릭스의 "총 이동비용 최적화 ❌(미확인)"을 △로 고친다

#### Chargeprice (유럽, 2026-07-29 경로 계획 출시)
- **사용자가 등록한 요금제 기준**으로 가장 싼 충전소에 서도록 경로를 계산, 출발 전 전체 비용 예측, 선호 네트워크·최소 충전 출력 설정. 자동차 제조사·내비용 B2B API도 제공
- 없는 것: 차량 데이터, 보상, 차 안 앱. 국내 서비스 아님

#### 기타
- Kia ccNC 루트 플래너(2025-03 OTA, 유럽): 도착 목표 잔량·충전소 도착 최소 잔량 설정. 요금 기준 추천은 확인 안 됨
- 한전 × 티맵 "차징플래너": 경로상 충전소를 상태·요금 고려해 추천, 예약·결제
- 카카오내비: 충전소를 경유지·목적지로 넣으면 도착 전까지 충전기 상태 안내
- Pleos 앱 마켓(18종)에 EV 충전 전용 앱은 여전히 확인되지 않음

## 4. 기획에 반영할 것

1. **보상 재원(⑤)은 선례로 설명한다** — 해외 Optiwatt·ev.energy(전력회사가 비피크 충전에 지급), 국내 한전 플러스DR(수요자원 등록 + 충전사업자 할인 + ChargeLink 중개). "우리 앱 = DR 제도의 소비자 접점"
2. **블루링크와 축을 나눈다** — 안전 → 보험료(블루링크) vs 효율 → 충전비(우리). 연동 가능성을 제안
3. **결제는 카페이 연동 전제** — 직접 결제망을 만들지 않는다
4. **빈 카테고리 진입** — Pleos 앱 마켓에 EV 충전·금융·리워드 앱이 아직 보이지 않음
5. **돈 중심, 게임은 보조** — 연구 근거상 게이미피케이션 단독 효과는 약함
6. **포인트 설계 주의** — 현금처럼 쓰이면 선불전자지급수단(전자금융거래법) 해석 가능 → "포인트 → 제휴 충전소 할인 쿠폰" 형태

### 차별점 한 줄

> **"차량 센서가 검증한 효율 운전과 충전 선택을, 실제로 아낀 돈과 수요 분산 보상으로 돌려주는 Pleos 차량 앱"**
>
> 운전 → (차량 검증) → 절약 + 보상 → (카페이 정산) → 더 싼 충전 선택 → (DR 재원) → 다시 운전
