# 현대자동차그룹 차량용 앱 개발 공모전 — 상세 정리

> **Code your App into Pleos App Market**
> 출처: <https://appdevchallenge.auto-hmg.io/> (2026-10-25 기준 사이트 전수 확인: 홈 / 참가가이드 8개 섹션 / FAQ 전체 / 공지 3건)

- 1차에 제출한 산출물은 2차 PT 전까지 **자유롭게 고도화 가능**.

### 동의서 / CC 규칙
- 개인 참가자 또는 대표자와 팀원 **전원(최대 5인)이 각각** 동의 여부·서명·날짜 작성.
- 대표자가 **팀원 전원을 참조수신(CC)** 하여 발송.
- 수집 항목: 성명, 소속(선택), 휴대폰번호, 이메일 주소, 팀원정보(팀 참가 시), 서명.
- 보관: 공모전 및 연계 행사 종료·후속일정(**2027.02.28**)까지 보관 후 지체 없이 파기. 수상자는 결과 발표일로부터 **2년** 보유 후 파기.

### 수정 제출
- 마감 전까지 **처음 제출한 이메일 주소로** 수정 자료를 재발송.
- 여러 번 제출한 경우 **마감 전 마지막 제출 자료**를 최종본으로 심사.
- 제목: `[수정제출] [차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명`
- 수정 제출 시에도 **전체 제출 자료 + 서명한 동의서 전부 재첨부**, **팀원 전원 CC** 필수 (미이행 시 유효 접수로 인정되지 않음).

### GitHub 저장소 제출 규칙
- 새 저장소 또는 기존 개발 저장소 사용 가능. 소스 코드 업로드.
- APK는 저장소 내 **`apk/` 폴더**에 업로드. 파일명: **`팀명_앱이름_release.apk`**
- APK는 **실행 가능한 release 버전**.
- 용량 초과 시 **GitHub Releases**에 등록하고 Release 페이지 주소 제출.
- **Private 저장소도 가능** — 공지된 **심사용 GitHub 계정을 Collaborator로 초대**, 마감 전 접근 가능 여부 반드시 확인.
  - ⚠️ 개인 계정 Private 저장소는 Collaborator에게 **읽기+쓰기 권한**이 모두 부여되므로 초대 전 권한 확인.
- `README.md` 필수 기재: 앱 이름 및 한 줄 소개 / 실행 방법 / 테스트 환경 및 필요 설정 / APK 위치 또는 Release 링크
- ⚠️ **APK만 따로 제출하지 말고** GitHub 저장소에 소스 코드와 함께 업로드.

## 5. 개발 환경 — Pleos

- **Pleos**: 현대자동차그룹의 소프트웨어 중심 모빌리티 브랜드
- **Pleos Connect**: 차량용 인포테인먼트 플랫폼
- **Pleos Playground**: Pleos 개발자 포털 (개발 문서·도구·가이드)

### 요구사항
- **Android API 28 이상**
- **Gradle 8.0 이상**
- **Java 또는 Kotlin**
- (문서에 대응하는 SDK 버전은 Pleos 개발 문서 동일 페이지에 명시)

### Pleos Connect SDK (5종)

| 용도 | SDK |
|---|---|
| 차량 상태 | **Vehicle SDK** |
| 위치 정보 | **FusedLocation SDK** |
| 길 안내 연동 | **NaviHelper SDK** |
| 음성 입출력 | **TextToSpeech SDK** · **SpeechToText SDK** |

- 각 SDK의 제공 상태·사용 조건은 공식 문서 기준.
- 에뮬레이터 등 개발 도구로 구동 검증 및 보완 가능.

### 공식 문서
- Pleos Connect 개발 환경 설정 가이드 (에뮬레이터 사용법 포함)
- Pleos Playground 개발 문서 포털
- Pleos Connect SDK API 참조 문서
- Vehicle SDK 튜토리얼

### 예시 시나리오 (참고용, 주제 제한 아님)
- **음성 메모 앱** — SpeechToText SDK로 주행 중 음성을 메모로 저장
- **안전운전 점수 앱** — Vehicle SDK 차량 상태 데이터로 주행 습관 점수화
- **배달 기사용 앱** — NaviHelper SDK로 경로 안내 연동, 배달 동선 지원

## 6. 심사

### 심사 구조
- **1차 서류심사** — 접수양식(기획서) 기반. 통과 **20팀** 선정.
- **2차 최종 PT 심사 (오프라인)** — 핵심 기능을 구현해 발표·시연. 실제 동작 앱 시연 필수.
- 최종 **10팀** 선정 → 2027.02 행사에서 최종 순위 발표.

### 1차 서류심사 평가 항목 (세부 배점 비공개)

| 항목 | 평가 내용 |
|---|---|
| **차량 특화성** (필수) | 모바일 대비 차량 환경만의 독자적 가치와 우위를 제공하는가 / 주행·정차 맥락 및 차량 기능과 유기적으로 결합되었는가 |
| **창의성** (필수) | 기존에 없던 독창적·혁신적 아이디어인가 / 운전자·동승자의 Pain Points & Needs가 명확히 정의되고 해결 방식이 명확한가 |
| **기술 활용성** (필수) | Pleos Playground 제공 SDK·API를 앱의 **핵심 기능과 사용 경험에** 적절히 활용했는가 |
| **사업성** (필수) | 타깃 고객이 명확하고 사용자 확보·지속 이용·확대 가능성이 있는가 (타깃 분석, 예상 MAU, Retention Rate, 서비스 확대 계획 등) |
| **[가산점] 개발 산출물** (선택) | 프로토타입 시연 영상(화면 녹화 포함) / GitHub 저장소 링크(소스 코드 및 APK 포함) |

### 순위 확정 방식
- **최종 순위는 2차 PT 심사에서 제출·시연한 결과물을 기준으로 확정**.
- PT 심사 이후 행사 전까지는 오류 수정 등 일부 보완만 가능하며, **추가 개발은 최종 순위 평가에 영향 없음** → 전시 준비와 현장 시연 안정화에 집중.
- 제출 결과물의 정상 구동·시연 가능 여부를 확인하며, 필요 시 보완 요청 가능.

### 추후 안내 예정
- 2차 PT 심사 기준
- 수상팀(10팀) 전시 준비 기간 준수사항 (수정·보완 범위, 추가 제출물과 기한)

## 8. 숏폼 챌린지 (별도 특별상)

- **시상**: 1팀 · 상금 50만원 + 2027.02 현대자동차그룹 공식 행사 시상식 현장 초청 및 공식 시상
- **본상 수상 여부와 무관하게 독립적으로 심사·선정**
- **기간**: 2026.10.21 ~ 2026.11.15 (공모 접수 기간과 동일)
- **발표**: 당선작 개별 연락 + 공지사항 안내

### 참여 방법
1. **촬영** — 앱 아이디어나 화면을 **30초~1분 이내 세로 방향 영상**으로 제작
2. **게시** — 개인 또는 팀 계정의 **Instagram 릴스** 또는 **YouTube Shorts**에 게시
3. **링크 제출** — 게시물 링크를 접수양식(기획서)에 기재해 이메일로 함께 제출 (**선택, 가산점 없음**)

### 해시태그
- **[필수 지정]** `#HMG차량용앱개발공모전`
- **[제안]** `#PleosAppMarket` `#HMG앱공모전`
- 필수 해시태그 1개 포함, **총 2~3개**를 본문 또는 설명란에 달아야 정상 참여 인정

### 게시물 구성 가이드 (3S)
1. **Spot** — 어떤 순간에 주목했나요? (불편했던 순간, 바꾸고 싶은 경험)
2. **Solve** — 앱 화면과 핵심 기능으로 해결 방법 소개
3. **Scene** — 목업·프로토타입으로 앱 사용 씬 보여주기

### 유의사항
- 숏폼 참여·링크 제출은 선택이며 가산점 없음.
- 제출 영상은 현대자동차그룹 행사 시상식에서 사용될 수 있음.
- 초상권·저작권 등 문제 발생 시 민·형사상 책임은 **응모자 본인**에게 있음.

## 9. 참가·출품 유의사항 (공지사항 전문 요약)

### 출품 및 접수
- 모든 출품작은 **참가자의 순수 창작물**이어야 하며, 표절작 또는 **기 발표된 타 공모전 수상작은 심사 제외**.
- 제출 서류 내용이 사실과 다를 경우 **선정 취소** 가능.
- 마감일 이후 제출 서류는 인정되지 않으며, 지원자 실수로 인한 파일 오류·파손 책임은 지원자에게 있음.
- 잘못된 개인정보 입력으로 응모가 정상 완료되지 않는 경우 책임은 응모자에게 있음.
- 현대자동차그룹 임직원은 참가 가능하나 **최종 수상 대상에서 제외**.
- 응모 과정의 고의·과실로 인한 법적 문제는 응모자 책임. 입상 후 밝혀지면 **수상 취소 및 상금 환수**.

### 심사 및 시상·현장 시연
- **세부 심사기준 및 과정은 공개하지 않음**.
- 공모 일정은 주최 측 사정으로 예고 없이 변경될 수 있으며, 응모작 수와 심사 기준에 따라 **시상 작품 수가 조정되거나 수상작이 없을 수 있음**.
- 1차 합격팀(20팀)은 2차 오프라인 PT에서 **실제 동작 가능한 앱 시연 필수**.
- 최종 10팀은 전시 구동용 최종 APK 제출 + 2027.02 행사 현장 시연·시상식 참석 **의무**.

### 지적재산권(IP) 및 법적 분쟁
- 출품작은 제3자의 권리(초상권, 저작권, 디자인권 등)를 침해하지 않아야 하며, 분쟁 발생 시 대응 및 민·형사 책임은 **응모자**에게 있음.
- 상금 수령 이후에도 이의신청·표절 시비·저작권 침해 등 분쟁 발생 시 **수상 취소 및 상금 전액 환수**.
- 출품된 모든 자료의 지식재산권은 **응모자에게 귀속**. 단, **수상작**에는 아래 기준 적용:
  - 주최측은 수상 아이디어에 대한 **「통상실시권」**을 가질 수 있음 (사용대가·실시범위·사용기간 등은 **상호 협의**하여 결정).
  - 주최측은 수상 아이디어에 대해 **결과 발표일로부터 4개월간 지식재산권 양도 등에 관한 「우선협상권」**을 가질 수 있음.
  - ※ 주최자는 비영리 공익 목적으로 입상작을 복제·전송할 수 있고, 입상자와 별도 합의를 통한 이용허락을 얻어 2차적 저작물 작성 및 수익 창출 가능. 공고된 범위를 넘는 이용은 입상자와 별도 합의.

### 상금 지급 및 제세공과금
- 상금은 **대표 신청자에게 일괄 지급**되며 분할 지급되지 않음. (팀 내 분쟁에 대해 주최 측은 중재·조정 책임 없음)
- 상금 지급 시 입력 개인정보는 수령인과 일치해야 하며, 불일치 시 당첨 취소.
- 수상자 오기재로 인한 상금 미지급은 주최 측 책임 아님.
- 상금의 **제세공과금(기타소득세 등)은 관련 세법에 따라 원천징수 후 지급**.

### 제출물 보관 및 폐기
- 응모자 요청에 따라 제출 자료 반환·폐기 가능. 별도 요청이 없으면 **공모전 및 행사 종료일(2027.02.28) 후 즉시 폐기**.
- 수상작은 세무 신고 증빙 및 후속 지원 이력 관리를 위해 **2년간 보유 후 폐기**.
- 기타 정하지 않은 사항은 주최 측 결정에 따름.

## 10. FAQ 핵심 정리

**참가 자격 · 팀**
- 개인 또는 **최대 5인 팀**. 대표자와 팀원 전원이 각각 동의서에 동의·서명·날짜 작성, 대표자가 팀원 전원 CC하여 이메일 제출.
- 팀 접수 시 대표자와 팀원 전원의 **성명·소속·휴대폰번호·이메일**을 접수양식에 기입.

**접수 · 제출물**
- **기획서(접수양식)만으로 지원 가능.** 개발 산출물은 필수 아니지만 제출 시 가산점.
- 단, 2차 PT 대상 팀은 PT 전까지 실제 동작 앱 개발 완료 필수.
- APK만 따로 제출 X → GitHub 저장소에 소스 코드와 함께 업로드.
- Private 저장소 제출 가능 (심사용 계정 Collaborator 초대 + 접근 확인 필수).
- 접수양식은 `지원·제출 방법` 페이지에서 다운로드.

**개발 환경 · SDK**
- Pleos Connect 환경 이해 → Pleos Playground 문서로 기획 → Pleos Connect SDK로 개발.
- **접수양식 5번(개발 계획)** 에 Pleos Connect 환경에서의 구현 방식, 주요 개발 범위, SDK/API 사용 계획을 **구체적으로** 작성.
- 사용 가능 SDK: Vehicle, NaviHelper, TextToSpeech, SpeechToText, FusedLocation.

**심사 · 시상**
- 필수 4항목(차량특화성·창의성·기술활용성·사업성) + 개발 산출물 가산점.
- 결과 발표: 1차 11/23 → 2차 PT 12/3~4 → 최종 선정 12/18 → 최종 순위 2027.02.
- 전시 준비 기간에는 신규 기능 개발이 아니라 **전시 영상 제작 협조 + 최종 구동용 APK 제출 + 구동 안정성 테스트**.

**기타**
- 설명회: 2026.10.28(수) 온라인 1회, 다시보기 제공. 시간·링크는 공지사항 안내.
- 추가 문의: FAQ·공지사항 확인 후 **appdevchallenge@hyundai-partners.com**
