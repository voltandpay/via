# 시연 시나리오 (1차 영상 · 2차 PT)

> 대상 빌드: `feat/mvp-1` · 디버그 빌드에는 오른쪽 위 **DEV** 버튼(시연 패널)이 있다. 릴리스 빌드에는 없다.
> Virtual Console 조작은 `tools/vc.sh`로 한다(연결이 잠깐 끊겨도 다시 시도한다). 먼저 `adb forward tcp:8088 tcp:8088`.

## 0. 준비 (공통)

1. 에뮬레이터 `Pleos_Connect_v2.1` 부팅(cold boot), `adb forward tcp:8088 tcp:8088`
2. 디버그 APK 설치: `./gradlew :app:installDebug`
3. 앱 첫 실행 → 위치·마이크 권한 **허용** → 온보딩에서 **아이오닉 5 롱레인지**, 멤버십 **채비** 선택 → 시작하기
4. 초기 상태: `tools/vc.sh gear Park`, `tools/vc.sh charge off`, `tools/vc.sh soc 15`
5. 위치를 출발지(판교)로: `adb emu geo fix 127.0974 37.4128`
6. ⚠️ **SoC와 Battery Energy는 따로 움직인다**(스파이크 2-2). Virtual Console 웹 화면(http://127.0.0.1:8088)에서 Battery Energy도 15% 수준(약 11.6kWh)으로 맞춰야 내비의 배터리 표시와 앞뒤가 맞는다.

## 2. Mock 모드 (Virtual Console 없이 — 예비)

DEV → **MOCK 모드로**(앱이 다시 시작됨). 이후 DEV 패널 버튼만으로 진행한다.

1. **SoC 15** → **서울역 안내** → **주행**: 주행 카드 "도착 예상 배터리 9%", 추천 양재 채비, 음성 질문
2. **정차** → 홈의 **경유지로 추가** 또는 **충전소 비교** 탭에서 추가
3. **밤 11:30으로** → **양재 채비 도착** → **충전 시작**: 충전 화면 +40P(충전 10 + 스탬프 20 + 이벤트 10), 음성 "새 스탬프 획득!"
4. **충전 끝** → 1분 뒤 **충전 끝** 한 번 더(세션 종료) → **정차** → 도감·포인트 탭
5. **효율 트립 종료** → 포인트 +10

## 3. 알려진 제약
- 에뮬레이터에서 전비 API는 미지원 → 차종 기본 전비(아이오닉 5: 5.0km/kWh)로 계산한다.
- VIN이 `"invalid"`라 차종은 온보딩에서 고른다.
- 내비 앱이 준비되기 전 경유지 요청은 버려진다 → 경로 안내가 시작된 뒤에 진행한다.
- **Virtual Console은 웹 페이지(http://127.0.0.1:8088)가 브라우저에 열려 있고 앞에 보일 때만 동작한다.** 페이지를 닫거나 다른 탭으로 가거나 브라우저 창이 가려지면 몇 분 안에 `emulator_inactive`가 된다(재부팅으로는 안 고쳐짐) → 시연 중에는 콘솔 탭을 앞에 띄워 둔다. (2026-10-26 확인)
- 경유지가 추가되면 **내비 앱이 앞으로 나오며** "경유지 1개 포함"으로 재탐색한다. 우리 앱의 로딩 표시는 그 뒤에 가려진다 → 앱으로 돌아오면 홈에 "경유지로 추가한 충전소"가 보인다.
- 음성 질문은 **경로가 정해진 순간** 나온다(정차 중이어도). 목적지를 정하고 8초 안에 답하지 않으면, D단으로 바꿨을 때 주행 카드에 "대답을 듣지 못했어요"가 바로 보인다.
- 요금은 공개 범위 안의 근사값이다(`core/src/main/resources/mock/README.md`).
