# Pleos Connect UI 디자인 가이드 정리 — VIA 화면 개선용

> 작성일: 2026-10-26 · 출처: [Pleos Connect UI Design Guide](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro) (Introduction · Foundations · Getting started · Components · Experiences), [운전자 주의 분산 요소 최소화](https://document.pleos.ai/docs/pleos-only/distribute/app-review-guide/review-driver-distraction-elements)
> 목적: 시연 영상·2차 PT 전에 VIA 화면을 Pleos 시스템 UI와 맞추기 위한 기준. 수치는 가이드 본문과 이미지(SVG·PNG 표)에서 읽은 값이다.

---

## 1. 꼭 지켜야 할 원칙 (심사와 직결)

| 원칙 | 가이드 내용 | VIA 현재 | 조치 |
|---|---|---|---|
| **응답 0.25초** | 입력 후 0.25초 안에 반응, 오래 걸리면 진행 중임을 시각적으로 표시 | 경유지 추가 터치 후 최대 5초간 표시 없음 | 버튼 **Loading 상태**(버튼 안 로더 + 비활성) |
| **한눈에(1~2초)** | 핵심 정보만, 불필요한 요소 배제 | 주행 카드는 대체로 지킴 | 주행 카드 정보 위계 재정리 |
| **주행 중 시선 유도 금지** | 동영상·애니메이션 이미지·텍스트 자동 스크롤 금지 | 해당 없음 | 주행 중 화면에 애니메이션 넣지 않기 |
| **한 손·단순 조작** | 양손 조작·복잡한 제스처 금지 | 지킴 | — |
| **대비 4.5:1 이상** | 아이콘·텍스트·이미지 | 다크 배경 + 흰/회색 글자, 대체로 지킴 | 회색 보조 글자(`#8B95A3`) 대비 점검 → 가이드 텍스트 토큰으로 교체 |
| **문장 길이** | 한 줄 80자(영문 기준) 이하, 단락 3줄 이하 | 충전 화면 한 줄이 김("80%까지 약 … · 비회원가보다 … 절약 예상") | 두 줄로 나누고 핵심 숫자 강조 |
| **글자 크기** | 중요 정보 높이 5mm 이상, 보조 3mm 이상, 최소 12sp | 큰 편 | 아래 타이포 스케일로 통일 |
| **주야간 모드** | 조명에 따라 밝기·대비 자동 조정 | **항상 다크** | 라이트/다크 두 테마, 시스템 설정 따름 |
| **다양한 디스플레이** | 앱 창은 **가로·세로 두 레이아웃 모두** 지원해야 함(분할 화면) | **가로만 가정** | 세로(폭 840dp 이하) 레이아웃 추가 |
| **다국어** | 다국어에 적합한 UI | 한국어 하드코딩 | 문자열 리소스로 분리(2차 이후) |
| **알림** | 운전자에게 필요한 경우만, 광고 금지 | 알림 없음 | — |
| **음성 활용** | Gleo AI 등 음성 인터랙션 검토 | TTS·STT 사용 | 장점으로 유지 |

> 심사 문서 원문: "가이드 전반의 준수는 위험 요소의 완전한 배제를 의미하지 않으며, 추가 위험 요소가 있다고 판단될 경우 앱 등록이 거부될 수 있다." VIA는 미디어 앱(동영상·게임·브라우저)이 아니므로 주행 중 실행 제한 대상은 아니다 — 게임 요소를 "게임"처럼 보이게 만들지 않는 것이 중요.

## 2. 레이아웃 — 앱 창 크기

Pleos 화면 = 상태 표시줄(위) + 드라이빙 뷰(왼쪽) + GNB(아래) + **앱 창**. 앱 창에는 앱이 1개 또는 2개 뜬다.

| 디스플레이 | 해상도 | dpi | 앱 창 가로 모드(dp) | 앱 창 세로 모드(dp) |
|---|---|---|---|---|
| **Connect-S-17 (기본, 에뮬레이터)** | 2560×1440 | 160 | **1700×1164** | **840×1164** |
| Connect-S-14.6 | 2048×1152 | 200 | 약 1560×948 | 약 472×948 |
| Connect-L-12.9 | 1920×1080 | 160 | 1274×855 | 628×855 |
| Connect-W-Standard | 3840×860 | 160 | 1640×810 | 800×810 |
| Connect-W-Extended | 3840×1440 | 160 | 1640×1400 | 800×1400 |
| Connect-WF | 3072×816 | 200 | 1256×800 | 648×800 |

(14.6" 행은 표 이미지 해상도가 낮아 근사값)

**VIA에 주는 의미**
- 기준은 가로 1700dp, 하지만 **세로 840dp·높이 810dp(W-Standard)에서도 깨지지 않아야** 한다.
- 폭이 넓으면 2열(카드 나란히), 좁으면 1열로 바뀌는 반응형 구성.
- 상태 표시줄·공조 패널 등 시스템 UI가 앱 위를 잠시 덮을 수 있다 → 중요한 버튼을 화면 맨 위·맨 아래 가장자리에 붙이지 않는다.

## 3. 타이포그래피

- 서체: **Asta Sans** (System UI 기본, 한국어·영어). 캐릭터 강한 서체 지양. → 앱에 번들 가능한지 라이선스 확인 필요.
- 스케일 (size / line height, 단위 px = dp@160dpi):

| 계층 | Large | Medium | Small | 굵기 |
|---|---|---|---|---|
| **Headline** | 60 / 80 | 56 / 72 | 48 / 64 | Extra Bold, Bold |
| **Title** | 40 / 52 | 36 / 44 | 32 / 40 | Extra Bold, Bold, Regular |
| **Body** | 30 / 38 | 28 / 36 | 26 / 34 | Strong, Normal |
| **Label** | — | 24 / 28 | 20 / 24 | Normal |

**VIA 매핑 (현재 → 변경)**

| 쓰임 | 현재 | 변경 |
|---|---|---|
| 큰 숫자(도착 배터리 %, 절약액) | 150sp | Headline Large 60 + 숫자만 키우는 별도 Display(가이드 밖 → 최소화, 1개 화면 1개) |
| 화면·카드 제목 | Title 46sp | **Title Large 40 / Medium 36** |
| 본문 | Body 36sp | **Body Large 30 / Medium 28** |
| 보조 설명 | Caption 30sp | **Label Medium 24** (중요 정보 아님) 또는 Body Small 26 |
| 탭·버튼 글자 | 32~36sp | Body Medium 28 |

- 그림자: Level 1 (0, 6, blur 24, 8%) · Level 2 (0, 8, 32, 16% + 0, 2, 2, 8%) · Level 3 (0, 20, 40, 24% + 0, 2, 4, 20%)

## 5. 컴포넌트 — VIA에 쓸 것

| 컴포넌트 | 가이드 요점 | VIA 적용 |
|---|---|---|
| **Page Navigation** | 화면 **위쪽**: 앱 아이콘 + Primary 메뉴(드롭다운) + Suffix 아이콘, 하위 페이지는 Back | 현재 **아래쪽 탭바** → 위쪽 Page Navigation + Tabs로 이동 (시스템 GNB가 아래에 있어 겹쳐 보임) |
| **Tabs (Segmented menu)** | Box / Line 두 스타일, Fitted 옵션 | 홈·비교·도감·이벤트·포인트 → Line 탭 |
| **Basic button** | Pressed·Disabled·**Loading**(로더 표시 + 조작 불가) | "경유지로 추가"에 Loading 상태 |
| **버튼 인터랙션** | 모든 터치 요소 **눌림 시 95% 축소** + 배경색 변화 | 공통 Modifier로 적용 |
| **Toast** | 앱 패널 안 좌우·아래 여백 24, 최대 폭 792(메시지 712) | "경유지 추가됨", "새 스탬프" 확인용 |
| **System Popup** | Title·Description·확인/취소, Large/Medium | 포인트 쿠폰 "준비 중" 안내 등 |
| **Widgets** | 핸들·페이지·제목·정보 영역 | (선택) 홈 화면 위젯으로 "다음 추천 충전소" — 2차 이후 |
| Indicator / Spinner | 값 선택용 | 쓰지 않음 |

## 6. 아이콘

- **앱 아이콘**: Android **Adaptive Icon**(Foreground 로고 + Background 분리), Pleos 그리드·브랜드별 마스킹은 Figma 템플릿 제공.
- **UI 아이콘**: 48×48dp 그리드, Filled / Outlined 두 타입, 텍스트 라벨과 함께.
- VIA 현재: 앱 아이콘 없음(안드로이드 기본), UI 아이콘 없음(글자만).
