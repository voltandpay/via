## 02 앱 프로젝트 소개 / 심사 자료

**앱명 / 프로젝트명:** VIA (Verified rewards · In-route · Affordable)

### 1. 앱 한 줄 소개

> **VIA는 운전 중 배터리와 목적지를 보고, 내가 가진 충전 멤버십 기준으로 가장 싸고 지금 쓸 수 있는 충전소를 음성 한마디로 경로에 넣어 주고, 아낀 돈과 효율 운전을 차가 직접 확인해 보상하는 Pleos Connect 앱입니다.**

### 2. 기획 배경

**주목한 순간 — "배터리가 부족한데, 어디서 충전해야 손해를 안 볼까?"**

국내 전기차는 약 110만 대(2026년 6월 등록 기준)로 늘었지만, 공용 충전은 여전히 운전자에게 '계산하기 어려운 비용'입니다.

- **같은 전기가 2배 가까이 비싸다.** 같은 1kWh가 사업자·회원 여부·속도에 따라 270~590원이고, 비회원가는 회원가의 최대 2배입니다. 완속 사업자의 57.9%는 현장에 요금을 표시하지 않습니다(한국소비자원, 2025.12).
- **싸게 충전하려면 카드가 여러 장 필요하다.** 할인을 받으려면 평균 4~5개 사업자 멤버십이 필요하지만(2025.5 보도), 충전소마다 내 카드 중 어떤 것이 가장 싼지 운전 중에 따져볼 방법이 없습니다.
- **추천대로 갔는데 고장.** 충전 이용자가 꼽은 불편 1위는 충전기 고장(52.7%, GS차지비 이용자 1,400명 조사, 2026.3)입니다.
- **요금 불만이 지금 가장 뜨겁다.** 국내 충전 앱 38종 리뷰 32,662건을 직접 수집·분석한 결과, 부정 리뷰 중 요금 언급 비중이 2025년 12.0%에서 **2026년 21.4%로 급증**했습니다(해외 30종 58,986건도 21.7%로 같은 추세). 특히 회원가·로밍가·비회원가로 나뉜 요금 '구조'에 대한 불만은 국내 126건으로, 리뷰가 1.8배 많은 해외(48건)보다 훨씬 많아 한국 특유의 문제입니다.

**왜 '차 안'에서 풀어야 하는가**

- 충전소를 고르는 순간은 대부분 **운전 중**입니다. 휴대폰 앱으로 요금표를 비교하는 것은 위험하고 불가능합니다. 차는 지금 배터리 잔량과 목적지를 이미 알고 있습니다.
- 운전·충전 보상은 휴대폰에서는 실패해 왔습니다. 국내 한 충전 앱의 '주행 캐시백'은 수동 시작·GPS 오류로 주행이 기록되지 않아 혜택이 축소되고 폐지되었습니다. 해외 보상형 충전 앱(Optiwatt, ev.energy) 리뷰의 20%는 차량 연결 실패이며 그중 87%가 부정적입니다. **차량 데이터를 직접 읽는 차량용 앱은 이 '검증' 문제를 구조적으로 해결합니다.**
- 사용자는 아껴주는 기능과 보상을 원합니다. 국내 충전 앱 리뷰에서 요금 관련 언급의 63%, 리워드 언급의 89%가 긍정이었습니다.

### 3. 앱 주요 기능 및 차량 특화 요소

| 핵심 기능 | 해결하는 문제 | 차량 특화 요소 (Pleos Connect) |
|---|---|---|
| **① 도착 잔량 예측** — 지금 배터리·전비·남은 경로 거리로 도착 시 배터리를 계산, 15% 아래면 충전 필요 판단. 정차 중 홈의 배터리 링(주행 가능 거리·도착 예상 눈금)과 경로 띠(출발 → 후보 충전소 → 목적지, 지점별 예상 배터리)로 한눈에 | 언제 충전해야 할지 감으로 판단 | 차량 배터리(SoC)·전비를 실시간 구독, 내비 경로 거리 연동 |
| **② 내 멤버십 기준 최저가 충전소 추천** — 경로 위 충전소를 내 카드 기준 실효 단가(회원가/로밍가/비회원가)와 우회 비용까지 더한 **총비용**으로 비교. 고장·사용 중·커넥터 불일치·도착 불가 충전소는 제외 | 요금 구조가 복잡해 손해를 봄, 고장 충전기 | 차종별 배터리 용량·커넥터, 현재 잔량으로 '닿을 수 있는 곳'만 추천 |
| **③ 음성 한마디로 경유지 추가** — "12km 앞 양재 충전소에 들르면 내 멤버십 기준 kWh당 221원 더 저렴해요. 경유지로 추가할까요?" → "응" | 주행 중 화면 조작 위험 | 내비 경유지 API로 경로에 바로 반영, TTS·On-device STT로 **주행 중 무터치** |
| **④ 충전 요금·절약액 표시** — 충전을 시작하면 위치로 충전소를 자동 인식해 적용 요금과 비회원가 대비 절약 예상액을 원 단위로 표시. 차를 세워 둔 충전 중(20~40분)에만 메달 진열장·충전 혜택 시즌·이 충전소 도감 메달 진행을 함께 보여 주고, 끝나면 충전 영수증 | 현장 요금 미표시, 얼마 아꼈는지 모름 | 차량 충전 상태 + 위치로 충전 세션 자동 감지 |
| **⑤ 차가 확인하는 보상** — 충전·새 충전소·이벤트 충전소·효율 운전에 포인트, 전기가 싼 경부하 시간대 충전은 2배(부스트), 주간 미션 3개(회원가 충전·효율 운전·새 충전소)와 미션 7개마다 리서치 돌파 보너스, 4주 단위 충전 혜택 시즌. 수집·시즌 화면은 차를 세워 둔 충전 중에만 보여 준다(메달 진열장·시즌 트랙). 사용자는 아무것도 누르지 않음 | 휴대폰 보상 앱의 기록 누락·조작 | 충전 상태·기어·주행거리 등 **차량 센서로 자동 검증** |
| **⑥ 포켓몬 도감식 충전소 도감 · 레이드형 이벤트 충전소 · 사업자 데이** — 번호·지역·출력 타입으로 나눈 도감. 추천에 나온 곳은 '발견', 충전하면 '등록'(3D 메달), 다시 충전하면 동 → 은 → 금, 지역을 다 모으면 보너스. "22시~02시 이 충전소 포인트 2배", 한 달에 하루 특정 사업자 포인트 3배 + 한정 메달 | 피크 시간·인기 충전소 쏠림, 다시 찾을 이유 부족 | 위치 + 시간 + 충전 상태로 자동 인정, 수집은 원래 지나가는 경로 위에서만, 화면은 정차 중에만 |
| **⑦ 멤버십 코치** — 최근 30일 실제 충전을 다시 계산해 "채비 카드가 있었다면 1만 9천 원 덜 냈어요"처럼 내 충전 습관에 맞는 카드 하나를 추천하고, 이미 있으면 한 번에 내 멤버십에 추가 | 할인을 받으려면 카드 4~5장이 필요한 가입 장벽, 어떤 카드가 내게 이득인지 모름 | 차가 자동으로 확인한 충전 기록(충전소·충전량)으로 계산 — 사용자가 기록할 것이 없음 |
| **⑨ 가는 도중 경유지 교체 · 장거리 충전 계획** — 경유지로 넣은 충전소가 도착 전에 사용 중·고장이 되면 "양재 채비 충전소가 지금 사용 중이에요. n km 앞 다음 충전소로 바꿀까요?"라고 묻고, "응" 한마디로 경유지를 바꿈. 서울→부산처럼 한 번 충전으로 안 되는 경로는 충전을 2~3곳으로 나눠 정류지마다 도착 배터리·충전 목표·요금을 계획하고, 한 곳 충전이 끝나면 다음 정류지를 이어서 추천 | 추천대로 갔는데 고장(불편 1위), 명절·주말 장거리 충전 계획 부담 | 내비 경유지 교체(지우고 다시 넣기), 차량 SoC로 정류지 충전 완료를 판단 |
| **⑧ 음성으로 묻기 · 월간 절약 리포트** — 말하기 버튼 하나로 "제일 싼 충전소 어디야?", "이번 달 얼마 아꼈어?", "도착하면 몇 퍼센트야?"에 바로 답하고, 가장 싼 곳은 이어서 "경유지로 추가할까요?". 매월 처음 정차할 때 지난달 절약액을 한 줄로 알려 주고 홈에 리포트 카드 | 운전 중 궁금한 것을 확인하려면 화면을 봐야 함, 아낀 돈이 체감되지 않음 | On-device STT·TTS로 주행 중 시선 이동 없이, 기어(정차)를 읽어 정차했을 때만 리포트 |

**차량 환경 설계 원칙**

- **주행 중**에는 상태 카드 1장과 큰 **말하기 버튼 하나**만 보이고, 안내·확인·질문은 음성으로만 합니다. 기어(P단 여부)를 차량에서 직접 읽어 판단하며, 기어를 알 수 없으면 안전하게 '주행 중'으로 봅니다.
- **정차 중**에만 충전소 비교·도감·이벤트·포인트 화면을 엽니다. **충전 중**에는 요금과 절약액을 보여줍니다.
- 게임 요소는 충전 유틸리티 안의 보조 기능입니다(게임 앱 분류로 주행 중 실행이 막히지 않도록). 집·아파트 완속 충전은 차 안에서 기다릴 일이 드물어(충전의 62.5%가 자택·공동주택, 자체 조사), 수집·시즌 화면은 **경로 위 공용 급속 충전(20~40분, 차 안에서 대기)** 화면에만 둡니다. 홈 첫 화면은 배터리·추천·아낀 돈이 먼저입니다.
- **차량·위치 데이터는 차 안에서만 처리합니다.** 충전·포인트 기록은 차량 기기 안에 남고 서버로 보내지 않습니다(1차는 서버 없음). 보상은 차가 확인한 사실에만 주고, 같은 충전소 충전 보상은 2시간에 한 번(플러그를 다시 꽂거나 앱이 다시 시작돼도 늘지 않음)입니다.
- 포인트는 현금성이 아니라 제휴 충전 할인 쿠폰으로만 교환합니다. 한 번 공지한 적립 기준은 시즌 중 줄이지 않습니다(리뷰에서 가장 반발이 컸던 지점).

### 4. 주요 사용 시나리오

**사용자:** 집 충전기가 없거나 출장·외근이 잦아 **공용 충전을 주로 쓰는 EV 운전자**. 충전 멤버십 카드 2~3장 보유.

**장면 A — 퇴근길, 배터리가 부족하다 (주행 중)**
1. 내비에 목적지(서울역, 23km)를 입력하고 출발한다. 배터리는 15%.
2. VIA가 도착 시 잔량을 9%로 계산하고, 경로 위 충전소 9곳 중 고장·사용 중·커넥터 불일치를 빼고 내 '채비' 카드 기준 총비용이 가장 싼 곳을 고른다.
3. 음성: "도착 시 배터리가 9%예요. 11km 앞 양재 채비 충전소에 들르면 내 멤버십 기준 kWh당 221원 더 저렴해요. 경유지로 추가할까요?"
4. 운전자: "응, 추가해줘." → 내비 경로에 경유지가 추가된다. 화면은 한 번도 만지지 않는다.
   (대답을 못 했다면, 다음 정차 때 홈 화면의 '경유지로 추가' 버튼 한 번으로 끝난다.)
5. 가는 도중 양재 채비가 사용 중이 되면 음성: "양재 채비 충전소가 지금 사용 중이에요. 다음 충전소로 바꿀까요?" → "응" → 내비 경유지가 바뀐다.
6. 가는 길에 궁금하면 말하기 버튼을 한 번 누르고 "이번 달 얼마 아꼈어?", "도착하면 몇 퍼센트야?"라고 묻는다. 답은 음성으로만 온다.

**장면 B — 충전소 도착 (충전 중)**
1. 충전기를 꽂으면 VIA가 충전 시작과 위치를 감지해 충전소를 자동 인식한다.
2. 화면: 적용 요금 299원/kWh(회원가), 80%까지 약 15,000원, **비회원가보다 약 11,000원 절약**.
3. 처음 온 충전소라 음성 "새 스탬프 획득!" — 충전 10P + 스탬프 20P가 자동 적립되고, 이번 주 미션 '새 충전소 1곳 등록'도 달성된다(+15P).
4. 충전 화면 아래에는 **메달 진열장**(3D 선반 위 도감 9곳의 메달, 지금 충전소는 크게)과 **충전 혜택 시즌** 트랙(4주 시즌 경험치와 코인·상자·시즌 메달 보상)이 보인다. 홈·주행 화면에는 없는 충전 중 전용 화면이다.
5. 충전이 끝나면 홈에 **충전 영수증**(충전량·결제 예상·비회원가 대비 절약·받은 포인트)이 뜨고, 도감에 양재 채비가 동 메달로 등록된다. 배터리가 충분해졌으니 경로 위 추천은 사라진다.

**장면 C — 레이드형 이벤트 충전소 (정차 중 확인 → 밤 충전)**
1. 정차 중 홈 화면에 "오늘 22시~02시, 양재 채비 충전소 포인트 2배".
2. 밤 11시 반 그 충전소에서 충전하면 위치·시간·충전 상태로 자동 인정돼 보너스가 붙는다.
3. 충전사업자는 한산한 시간대로 수요를 옮기고, 그 대가로 포인트 재원을 부담한다.

**장면 D — 주말, 쌓인 혜택 확인 (정차 중)**
1. 홈: 이번 주 미션 진행(예: 2/3 달성)과 리서치 돌파 스탬프, 최근 7일 절약 차트(요일별 금액). 매월 1~7일에는 맨 위에 **지난달 절약 리포트**("10월: 충전 9번, 비회원가보다 4만 2천 원 아꼈어요")가 있고, 달이 바뀐 뒤 처음 정차할 때 한 줄로 들려준다.
2. **멤버십 코치**: "이브이시스 카드가 있었다면 최근 30일에 2,560원 덜 냈어요" — 이미 가진 카드라면 [이미 있어요 · 추가] 한 번으로 다음 추천부터 회원가로 계산된다.
3. 도감: 지역 탭(서울 도심·강남·서초·경기 남부)별 진행 링. 추천에 나와 '발견'한 곳은 흑백 실루엣, 충전한 곳은 컬러 메달, 단골은 금 메달.
4. 포인트로 받을 수 있는 제휴 충전 할인 쿠폰("다음 쿠폰까지 60P")을 확인한다.

**장면 F — 명절, 서울에서 부산까지 (장거리)**
1. 배터리 40%로 부산역(410km)을 목적지로 잡는다. VIA: "부산역까지 충전이 2번 필요해요. 124km 앞 옥산휴게소 충전소에 들르면…"
2. 정차 중 홈에 **충전 계획** 카드: ① 옥산휴게소 8% → 80% · ② 경주휴게소 21% → 30% · 예상 요금 합계, 부산 도착 15%. 고장 난 휴게소와 커넥터가 안 맞는 곳은 처음부터 뺀다.
3. 옥산에서 80%까지 충전하면 "다음 충전은 228km 앞 경주휴게소 충전소예요. 경유지로 추가할까요?"

**장면 E — 사업자 데이 (커뮤니티 데이)**
1. 이벤트 탭에 "채비 데이 · 12/4(금) · 포인트 3배 + 한정 메달 · D-n".
2. 당일 홈 맨 위에 "오늘!" 카드. 채비 충전소에서 충전하면 사업자 데이 보너스와 보라 테두리 **한정 메달**이 도감에 남는다.
3. 사업자는 비용을 내고 신규·회원가 고객을 모으는 제휴 프로모션으로 쓴다(수익 모델 표 참고).

### 5. 개발 계획

**현재 상태: 1차 MVP가 Pleos Connect 에뮬레이터에서 실제 SDK로 동작합니다.** (장면 A~E 구현, 단위 테스트 184개, release APK 빌드)

**개발 환경**
- Android(Kotlin 2.2), minSdk 28 / targetSdk 34, Jetpack Compose
- Pleos Connect Emulator(Android 14 Automotive) + Virtual Console로 배터리·기어·충전 상태를 바꿔가며 검증
- 구조: 계산 로직(도착 잔량, 실효 단가·순위, 보상 규칙, 충전 세션 감지)은 Android와 분리된 순수 Kotlin 모듈로 만들어 단위 테스트로 검증하고, SDK는 Repository 계층 뒤에 두어 실차·에뮬레이터·시연(Mock) 모드를 바꿔 끼울 수 있게 했습니다.

**Pleos Connect SDK 사용 계획 (에뮬레이터에서 동작 확인 완료)**

| SDK / API | 사용 기능 | 앱에서의 역할 |
|---|---|---|
| **Vehicle – EvBattery** | 배터리 잔량(SoC) 구독, 배터리 에너지(Wh), 전비, 충전 스위치 상태 | 도착 시 잔량 계산, 충전 시작·종료 자동 감지 |
| **Vehicle – Gear** | 기어 선택 구독 | 주행/정차 판별 → 주행 중에는 말하기 버튼 하나뿐인 화면, 정차했을 때만 월간 리포트 |
| **Vehicle – Odometer** | 총 주행거리 | 주행(D→P) 거리 → 효율 운전 보상 검증 |

- Pleos 심사 기준 반영: 앱 실행 0.7초(기준 10초), 주행 중 터치는 말하기 버튼 하나, 시스템 패널을 뺀 우측 영역 기준 레이아웃.

### 6. 기대효과 및 발전 가능성

**사용자 가치**
- **돈:** 같은 충전량이라도 비회원가와 회원가 차이가 최대 2배입니다. 40kWh 충전 1회 기준 약 9,000원(kWh당 221원 차이 예시)까지 아낄 수 있고, 월 4회 공용 충전이면 월 3만 원 이상입니다.
- **시간·불안:** 고장·사용 중 충전기를 미리 빼고, 도착 가능한 곳만 추천해 '헛걸음'과 방전 불안을 줄입니다.
- **안전:** 운전 중 요금 비교를 위해 휴대폰을 만질 이유를 없앱니다.

**타깃 고객**
- 1차: Pleos Connect 탑재 현대·기아 전기차 운전자 중 **공용 충전을 정기적으로 쓰는 사람** — 공동주택 거주로 집 충전이 어렵거나, 영업·출장·장거리가 잦은 운전자. (충전의 62.5%가 자택·공동주택에서 이뤄지므로, 나머지 공용 충전 수요가 핵심 시장)
- 2차: 법인·렌터카·택시 등 공용 충전 의존도가 높은 사업용 EV.

**예상 MAU 〔추정〕**

Pleos Connect는 2026년 5월 신형 그랜저를 시작으로 적용되며 2030년까지 글로벌 약 2,000만 대 탑재가 목표입니다. 연도별 국내 EV 탑재 대수는 공개되지 않아 아래 가정으로 국내 MAU를 추정했습니다.

| 가정 | 값 |
|---|---|
| 국내 전기차 신규 등록 | 연 약 40만 대 (2026 상반기 19.9만 대 기준) |
| 그중 현대·기아 비중 | 50% |
| 신규 현대·기아 EV 중 Pleos Connect 탑재율 | 2027년 30% → 2028년 70% → 2029년 100% |
| 공용 충전 정기 이용자 비율 | 40% |
| 그중 VIA 사용률 | 25% (앱 마켓 상위 노출 가정) |

| 연말 기준 | 누적 Pleos EV (국내) | 예상 MAU |
|---|---|---|
| 2027 | 약 6만 대 | 약 6천 명 |
| 2028 | 약 20만 대 | 약 2만 명 |
| 2029 | 약 40만 대 | 약 4만 명 |

여기에 기아 전 차종 확대, 북미·유럽 출시(해외 충전 앱 리뷰에서도 요금 불만이 21.7%로 같은 추세), 법인 차량을 더하면 확장 여지가 큽니다.

**Retention Rate 목표 〔추정〕**

| 지표 | 목표 | 근거 |
|---|---|---|
| 1개월 유지율 | 60% | 공용 충전 이용자는 주 1회 안팎 충전 → 사용 계기가 매주 생김 |
| 6개월 유지율 | 40% | 차에 기본 설치되어 다시 찾는 비용이 없고, 충전이 필요할 때 **앱이 먼저 말을 거는** 구조 |

유지 장치: 차가 자동으로 확인해 쌓이는 포인트(사용자 노력 0), 포켓몬 도감식 충전소 도감(지역·발견/등록·동·은·금 메달), 매주 바뀌는 주간 미션과 리서치 돌파(미션 7개마다 큰 보상), 경부하 시간대 부스트, 공지한 적립 기준을 시즌 중 줄이지 않는 원칙. 미션·부스트는 모두 절약 행동(회원가 충전·효율 운전·싼 시간대 충전)에만 걸고, 주행 거리에는 보상하지 않는다.

**수익 모델과 서비스 확대**

| 단계 | 수익원 | 구조 |
|---|---|---|
| 1 | **이벤트 충전소 후원** | 충전사업자가 한산한 시간·장소에 이벤트를 걸고 비용 부담 → VIA가 운전자를 그리로 안내 (포켓몬 고의 스폰서 장소 모델) |
| 1 | **사업자 데이 후원** | 한 달에 하루, 특정 충전사업자 충전 시 포인트 3배 + 한정 메달(포켓몬 고의 커뮤니티 데이). 사업자가 포인트 비용과 노출 비용을 내는 제휴 프로모션 → 신규 회원 유입·회원가 전환 |
| 1 | **멤버십 가입 연결** | 멤버십 코치가 추천한 카드를 사업자 가입으로 연결(가입당 수수료). 사업자는 회원가로 다시 찾는 단골을 얻고, 운전자는 내 습관에 맞는 카드 하나로 회원가를 받음 |
| 1 | **제휴 할인 쿠폰** | 포인트 → 제휴 충전사업자 할인. 사업자는 신규 고객 획득 비용으로 부담 |
| 2 | **수요반응(DR) 연계** | 한전 플러스DR·국민DR 등 충전 수요 이동의 대가를 보상 재원으로 |
| 2 | **카페이 결제 연동** | 추천 → 경유지 → 충전 → 결제까지 차 안에서 끝 (그룹 결제 서비스와 시너지) |
| 3 | **'경유할 곳' 추천으로 확장** | 충전소에서 충전 중 머물 가맹점(카페·식당) 제휴로 확장 — *via*(경유) 브랜드의 본래 의미 |
